# RANDOM FOOTBALL

모바일 브라우저에서 플레이할 수 있는 2D 실시간 1:1 축구 게임의 실행 프로젝트입니다.

## 포함 기능
- Express 정적 웹 서버 + Socket.IO 실시간 통신
- 6자리 방 코드 생성 및 참가
- 서버 권한 기반의 경기 위치/공/점수 시뮬레이션
- 4인 팀(공격수/미드필더/수비수/골키퍼), AI 동료 이동, 선수 변경
- 슛, 패스, 질주, 골 판정, 3분 경기
- 모바일 가상 조이스틱과 버튼, PC 키보드
- 선수 뽑기와 브라우저 로컬 보관함

## 로컬 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 공개 배포 개요
이 프로젝트는 Express와 Socket.IO를 함께 사용하는 단일 Node.js 서비스입니다. 정적 사이트 전용 호스팅이 아니라 **WebSocket을 지원하는 Node.js 호스팅**에 배포해야 합니다.

일반적인 배포 순서:
1. 프로젝트 전체를 GitHub 저장소에 업로드합니다.
2. Node.js 웹 서비스 배포를 지원하는 호스팅 업체에서 새 Web Service를 만듭니다.
3. GitHub 저장소를 연결합니다.
4. Build command: `npm install`
5. Start command: `npm start`
6. 서비스가 제공하는 HTTPS 주소로 접속합니다.
7. 친구도 같은 주소에 접속하고, 한 명은 방을 만든 뒤 6자리 코드를 공유합니다.

무료 요금제의 제공 여부, 슬립/대기 제한, 월간 사용량, WebSocket 지원은 호스팅 업체 정책에 따라 바뀔 수 있으므로 배포 시 공식 요금제와 런타임 문서를 확인하세요.

## 환경 변수
- `PORT`: 호스팅 플랫폼이 지정하는 포트. 기본값 3000.

## 현재 구현의 범위와 제한
- 1대1 실시간 플레이는 같은 실행 서버의 Socket.IO 방에서 작동하도록 구성했습니다.
- 선수 뽑기/보관함은 현재 브라우저 `localStorage`에 저장됩니다. 계정 간 동기화나 결제 기능은 없습니다.
- 획득한 선수 능력치는 현재 뽑기/컬렉션 데이터이며, 실제 경기 선수 능력치에 아직 연결되지 않았습니다.
- AI 동료는 간단한 포지션 유지/공 근처 이동 로직입니다. 정교한 축구 전술 AI는 아닙니다.
- 재접속 후 진행 중 경기 복구, 계정, 랭킹, 안티치트 고도화, 관전자 기능은 포함하지 않았습니다.
- 코드가 생성되었다고 인터넷 배포까지 완료된 것은 아닙니다. 실제 HTTPS 주소는 호스팅 서비스에 배포한 뒤에 생깁니다.

## 헬스 체크
